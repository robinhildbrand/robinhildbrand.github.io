This website comes with a zero-configuration declarative plotting engine. You can easily embed interactive physics-based network graphs, mathematical curves, 3D surface plots, and LaTeX equations directly inside any Markdown blog post using standard code blocks.

⚡ How it works: Whenever you write standard Markdown fenced code blocks with language identifiers like ```network, ```function-plot, ```plotly, or ```mermaid, the client-side engine automatically renders them into responsive, interactive figures with zoom, pan, physics freeze, and PNG export controls.

1. Interactive Network Graphs

To plot a network graph with customizable nodes, edges, labels, colors, and physics simulation, use ```network:

```network { "title": "Complete Graph K5 with Custom Grouping", "height": "340px", "physics": true, "nodes": [ {"id": 1, "label": "v1 (Hub)", "group": "core", "size": 26}, {"id": 2, "label": "v2", "group": "peripheral", "size": 18}, {"id": 3, "label": "v3", "group": "peripheral", "size": 18}, {"id": 4, "label": "v4", "group": "peripheral", "size": 18}, {"id": 5, "label": "v5", "group": "peripheral", "size": 18} ], "edges": [ {"from": 1, "to": 2, "width": 2}, {"from": 1, "to": 3, "width": 2}, {"from": 1, "to": 4, "width": 2}, {"from": 1, "to": 5, "width": 2}, {"from": 2, "to": 3, "width": 1.5}, {"from": 3, "to": 4, "width": 1.5}, {"from": 4, "to": 5, "width": 1.5}, {"from": 5, "to": 2, "width": 1.5} ] } ```

2. 2D Mathematical Function Plots

Plot mathematical functions, derivatives, tangents, and trigonometric curves using ```function-plot:

```function-plot { "title": "Damped Oscillation: f(x) = e^{-0.25x} \sin(3x)", "height": "340px", "xDomain": [-1, 10], "yDomain": [-1.2, 1.2], "grid": true, "data": [ { "fn": "exp(-0.25*x) * sin(3*x)", "color": "#2563eb", "derivative": { "fn": "-0.25*exp(-0.25*x)*sin(3*x) + 3*exp(-0.25*x)*cos(3*x)", "updateOnMouseMove": true } }, { "fn": "exp(-0.25*x)", "color": "#94a3b8" }, { "fn": "-exp(-0.25*x)", "color": "#94a3b8" } ] } ```

Markdown Source Code:

```function-plot
{
  "title": "Damped Oscillation: f(x) = e^{-0.25x} \sin(3x)",
  "height": "340px",
  "xDomain": [-1, 10],
  "yDomain": [-1.2, 1.2],
  "grid": true,
  "data": [
    {
      "fn": "exp(-0.25*x) * sin(3*x)",
      "color": "#2563eb",
      "derivative": {
        "fn": "-0.25*exp(-0.25*x)*sin(3*x) + 3*exp(-0.25*x)*cos(3*x)",
        "updateOnMouseMove": true
      }
    },
    {
      "fn": "exp(-0.25*x)",
      "color": "#94a3b8"
    },
    {
      "fn": "-exp(-0.25*x)",
      "color": "#94a3b8"
    }
  ]
}
```

3. 3D Scientific Surface Plots (Plotly)

To plot 3D surfaces $z = f(x, y)$, use ```plotly with a declarative formula:

```plotly { "type": "surface", "title": "Saddle Surface z = \sin(x) \cdot \cos(y)", "fn": "Math.sin(x) * Math.cos(y)", "xRange": [-3.14, 3.14, 35], "yRange": [-3.14, 3.14, 35], "colorscale": "Viridis", "height": "400px" } ```

Markdown Source Code:

```plotly
{
  "type": "surface",
  "title": "Saddle Surface z = \sin(x) \cdot \cos(y)",
  "fn": "Math.sin(x) * Math.cos(y)",
  "xRange": [-3.14, 3.14, 35],
  "yRange": [-3.14, 3.14, 35],
  "colorscale": "Viridis",
  "height": "400px"
}
```

5. Academic Theorem Environments

Wrap mathematical statements in HTML theorem containers:

Theorem 1 (Courant-Fischer Min-Max Theorem)
Let $A \in \mathbb{R}^{n imes n}$ be a symmetric matrix with sorted eigenvalues $\lambda_1 \le \lambda_2 \le \dots \le \lambda_n$. Then: $$\lambda_k = \min_{U \subseteq \mathbb{R}^n, \dim(U) = k} \max_{\mathbf{x} \in U, \mathbf{x} eq \mathbf{0}} rac{\mathbf{x}^ op A \mathbf{x}}{\mathbf{x}^ op \mathbf{x}}$$
By the spectral decomposition $A = Q \Lambda Q^ op$, let $\mathbf{y} = Q^ op \mathbf{x}$, then apply the Rayleigh quotient directly.
